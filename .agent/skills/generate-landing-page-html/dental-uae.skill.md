# DENTAL UAE DEMO LANDING PAGE SKILL
Version: 1.0
Purpose: Generate high-converting, mobile-first demo dental clinic websites for the UAE market
Target Market: Bur Dubai, Dubai, UAE (expandable to other UAE areas)
Use Case: Demo / outbound sales landing pages (not client-owned production sites)

---

## CORE POSITIONING (NON-NEGOTIABLE)

These websites are for DENTAL CLINICS in the UAE.

Dental clinic customers:
- Compare 2–5 clinics before booking
- Care about trust, doctor credibility, hygiene, and results
- Often message on WhatsApp first
- Strongly respond to before/after proof and reviews
- Prefer fast appointments and clear pricing/financing options

The site must answer these questions immediately:
1. Are you a premium clinic in my area?
2. Are your doctors qualified (DHA / experience)?
3. Can I WhatsApp you instantly?
4. Do you have proof (before/after + reviews)?
5. Is booking fast and easy?

## GLOBAL DESIGN RULES

### UI Reference (MANDATORY)
Use the provided reference UI STRICTLY:
- Soft blue + white premium healthcare palette
- Rounded cards
- Clean spacing and soft shadows
- Big hero with photo on right side
- Clear CTA buttons
- Modern typography

The design must not be bland.
Add micro-interactions:

- Subtle lift + shadow on hover
- Smooth scrolling
- Clean focus states on inputs

## MOBILE-FIRST RULES (MANDATORY)

Mobile features required:
- Floating WhatsApp button
- Floating Call button
- Large tap targets
- All core info visible within 1–2 scrolls
- No heavy animations
- No autoplay video

## NAVIGATION RULES

Desktop:
- Top navbar with logo, links, and CTA
- Links: Home, Services, Doctors, Reviews, Contact
